## 4. A grade 2×2: os erros NÃO acumulam

Trajetória imposta (`tools/probe_pipeline_2x2.py`), então divergência de trajetória não existe por
construção:

```
B  so encoder 4 bits      9,10e-02
C  so difusor 4 bits      1,99e-01
B + C                     2,90e-01   se fossem independentes
D  os dois                1,99e-01   <- 0,1% de diferenca para C sozinho
```

**Quantizar o encoder em cima de um difusor quantizado não muda nada mensurável.**

E o mecanismo é posicional:

```
sigma      B (encoder)   C (difusor)
1.000       5,30e-01      6,16e-01
0.300       3,03e-03      5,33e-02
queda           175x           12x
```

O encoder erra **uma vez** e tem 8 passos para diluir. O difusor erra em **todos**.

### O VAE não é quantizável por esta bancada

`ae.safetensors`: **70 pesos 4D (convolução), ZERO 2D (Linear)**. Os três perfis casam 0 camadas.
Todo o caminho daqui é `convrot_w4a4_linear`, kernel de GEMM. Não existe kernel de convolução em
4 bits aqui — e é por isso que ninguém no ecossistema quantiza VAE. O VAE é **1,6%** do pipeline
do Z-Image (0,31 de 19,27 GiB).
